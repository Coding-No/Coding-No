## ⚙️ Coba dulu

```bash
git clone https://github.com/Coding-No/link-unlocker
cd link-unlocker
./run.sh mf <quickkey>          # Linux / Kali / Termux
src\link-unlocker.bat mf <key>  # Windows
```
