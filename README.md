## Cara gue ngerjain

**Cuma butuh Python. Nol `pip install`, nol `npm`, nol `curl`.** Pernah kejebak dependency yang ilang dari npm registry jam 2 pagi — nggak lagi.

Satu file kalo bisa. Satu folder kalo kepepet.

**Gue tes di HP kentang dulu.** Kalo di situ jalan, di server juga jalan.

Kalo ada yang nggak jalan, gue tulis di bagian **Limitations** — bukan gue diemin biar keliatan mulus.
